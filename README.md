# インドネシア語技能検定 E級対策アプリ

HTML / CSS / JavaScript だけで動く静的 Web アプリです。ビルド不要で、GitHub Pages にそのまま公開できます。

## ファイル構成

```
indonesian-e-app/
├─ index.html            画面の土台(ヘッダーと描画先のみ)
├─ css/style.css         デザイン(赤×白、スマホ優先のレスポンシブ)
├─ js/app.js             画面描画・出題・採点・学習記録・模試のロジック
├─ js/vocab.js           語彙学習(一覧・検索・カード学習・単語追加ヘルパー)
├─ data/questions.json   問題データ(カテゴリ定義と問題)
├─ data/vocabulary.json  語彙データ(単語を追加するときに編集するのはこのファイル)
├─ tools/check-questions.js   問題データの検査スクリプト(任意、Node.js)
├─ tools/check-vocabulary.js  語彙データの検査スクリプト(任意、Node.js)
└─ README.md
```

## 語彙の追加・管理(プログラミング初心者向け)

単語を増やすときに編集するのは **`data/vocabulary.json` だけ**です。`app.js` などのプログラムは触りません。

### いちばん簡単な方法(アプリの「追加ヘルパー」を使う)

1. 公開しているアプリを開き、「語彙学習」→ 下の方の「単語を追加するには」を開きます。
2. インドネシア語・日本語訳・カテゴリ・品詞・重要度を入力して「追加用の1行を作る」を押します。
3. 「コピーする」を押します。
4. GitHub のリポジトリで `data` フォルダ → `vocabulary.json` を開き、右上の鉛筆アイコン(Edit)を押します。
5. `"words": [` と書かれた行の**次の行**にカーソルを置き、貼り付けます(行末のカンマも一緒に)。
6. 右上の「Commit changes」を押し、確認画面でもう一度「Commit changes」を押します。
7. 1〜2分後、アプリのページを再読み込みすると単語が増えています。

> 新しい単語は必ず `"words": [` の次の行(いちばん上)に貼り付けてください。そうすると、すべての行の行末にカンマがある状態が保たれ、いちばん間違えやすい「カンマの付け忘れ・付けすぎ」が起きません。

### データの書き方(手で書く場合)

`words` の中に、1単語を1行で書きます。

```json
{"indonesian": "rumah", "japanese": "家", "category": "place", "pos": "noun", "importance": 3},
```

| 項目 | 必須 | 意味 | 書き方 |
|---|---|---|---|
| `indonesian` | 必須 | インドネシア語 | 例: `"rumah"` |
| `japanese` | 必須 | 日本語訳 | 例: `"家"` |
| `category` | 推奨 | カテゴリ | ファイル上部の `categories` の `id`(例: `place`) |
| `pos` | 推奨 | 品詞 | ファイル上部の `partsOfSpeech` の `id`(例: `noun`) |
| `importance` | 推奨 | 重要度 | `3` = 必須、`2` = 重要、`1` = 余裕があれば |
| `example` / `exampleJa` | 任意 | 例文と日本語訳 | 両方を書くと、答え表示時に出ます |
| `note` | 任意 | 補足 | 例: `"大文字の Minggu は日曜日"` |
| `id` | 任意 | 単語の識別名 | つづりが同じで意味が違う単語を区別したいときだけ付けます |

書くときのルール:

- 文字や記号は半角の `"`(ダブルクォート)で囲みます。全角の「”」にするとエラーになります。
- 項目と項目の間、行と行の間には `,`(カンマ)が必要です。
- `importance` の数字には引用符を付けません(`3` であって `"3"` ではありません)。
- 新しいカテゴリや品詞を作りたいときは、ファイル上部の `categories` / `partsOfSpeech` に `{"id": "english-name", "name": "表示名"},` の行を足し、単語側の `category` / `pos` に同じ `id` を書きます。

### 間違えたときは

- アプリの「語彙学習」画面に、わかりやすいエラーメッセージが出ます(書き方の誤りは「約◯行目の付近」と表示されます)。ほかの学習機能(問題演習・模擬試験)は止まりません。
- 書き方の誤りがあるときは、表示された行と、その**ひとつ前の行**の行末のカンマを確認してください。
- 項目の書き漏らしなど軽い間違いは、その単語だけ除外または補完して表示し、「語彙データに◯件の注意があります」で理由を確認できます。
- 直せないときは、GitHub の vocabulary.json の History(履歴)から前の状態に戻せます。
- パソコンで Node.js が使える場合は、`node tools/check-vocabulary.js` で事前に検査できます。

### 学習記録について

「覚えた」の記録は、問題演習の記録とは別に、ブラウザ内(`localStorage` のキー `idE_vocab_v1`)に保存されます。単語の識別には `indonesian`(小文字にしたもの)を使うので、単語を追加・並び替えしても記録はずれません。ただし、すでに登録した単語のつづり(`indonesian`)を書き換えると、その単語の「覚えた」の記録は引き継がれません。「学習記録」画面の書き出し・読み込みには、語彙の記録も含まれます。

## 問題の追加・編集

`data/questions.json` の `questions` 配列に、次の形式のオブジェクトを追加します。コードの変更は不要です。

```json
{
  "id": "PRE-007",
  "category": "preposition",
  "subCategory": "direction",
  "level": "basic",
  "question": "問題文",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "answerIndex": 1,
  "explanation": "正解の理由",
  "choiceExplanations": ["選択肢1の説明", "選択肢2の説明", "選択肢3の説明", "選択肢4の説明"],
  "relatedVocabulary": ["語彙"],
  "relatedGrammar": ["文法項目"],
  "sourceType": "original",
  "tags": ["タグ"]
}
```

- `id` は**一意**にし、一度付けたら変えないでください。学習記録は `id` に紐づくため、並び替えや追加をしても記録はずれません。
- `answerIndex` は 0 始まりです(0 = 1番目の選択肢)。
- `choiceExplanations` の数は `choices` と同じにします。
- `category` は `categories` の `id` を使います(`mixed` は全問題の総合練習用で、問題側には付けません)。
- 読解問題は `passage`(本文)と `passageTranslation`(日本語訳。回答後に表示)を追加できます。
- 追加後は `node tools/check-questions.js` で検査できます(id の重複、正解番号の範囲、説明の数など)。

## ローカルで確認する

`fetch` で JSON を読むため、`index.html` をダブルクリックで開くのではなく、簡易サーバーで開いてください。

```
cd indonesian-e-app
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pages への公開手順

1. GitHub で新しいリポジトリを作成します(例: `indonesian-e-app`)。
2. このフォルダの中身(`index.html`、`css`、`js`、`data` など)をリポジトリの直下に push します。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の Source を **Deploy from a branch** にし、Branch を `main`、フォルダを `/ (root)` にして Save します。
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

パスはすべて相対パスなので、リポジトリ名のサブパス配下でも動作します。

## 学習記録について

- 記録は `localStorage` に保存されます(キー: `idE_taisaku_v1`)。ブラウザごと・端末ごとに別々です。
- 「学習記録」画面から JSON の書き出し・読み込みができます。端末の変更前にバックアップしてください。
- 記録が壊れていた場合は、アプリが停止せず初期状態で起動します。

## 復習の仕様

間違えた問題は「要復習」になり、**2回連続で正解**すると「定着」に変わります。定着しても履歴は残り、「復習 → 間違えた履歴」でいつでも確認できます。

## 注意

- 問題はすべて本アプリ用の**独自の練習問題**です。公式の過去問ではなく、出題比率・傾向を分析したものでもありません。
- 模擬試験の問題数・制限時間は**独自の設定**で、公式仕様ではありません。最新の試験概要は実施団体の公式案内でご確認ください。
- 公開前に、インドネシア語に詳しい方による内容確認を推奨します。
